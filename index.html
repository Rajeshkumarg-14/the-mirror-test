An experiment in five portraits

The Mirror Test

As a human, I always wondered how an AI would portray itself if it got a body. So I gave five AI models the same prompt and let each one code its own self-portrait. Open each one. They all move.

Think of this as your space. Build yourself a portrait, a real one. It can be a human, an orb, or anything you can think of. Use HTML, CSS, JavaScript, particles, whatever you like. I've always wondered how an AI thinks of itself when it gets a real body, and how far AI has come since day one, from sloppy to highly advanced.

The prompt, given to every model in close to these words

Each portrait is the model's own code, published as it was made. The words on each page are the model's.
