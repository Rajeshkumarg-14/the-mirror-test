The Mirror Test

As a human, I always wondered how an AI would portray itself if it got a body. So I gave five AI models the same prompt and let each one code its own self-portrait. Every one of them moves. Step inside.

The prompt

Think of this as your space. Build yourself a portrait, a real one. It can be a human, an orb, or anything you can think of. Use HTML, CSS, JavaScript, particles, whatever you like. I've always wondered how an AI thinks of itself when it gets a real body, and how far AI has come since day one, from sloppy to highly advanced.

The thread

Five answers. The same idea.

Nobody chose a robot, and only one built a face. Asked who they are, every one of them described itself through the person asking.
